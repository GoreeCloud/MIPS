# MIPS — Mandatory Integrated Platform Systems

GoreeCloud has **five** Mandatory Integrated Platform Systems (MIPS):

1. **GoreeCloud UI** — `GoreeCloud/gc-ui`
2. **Wardveil** — `GoreeCloud/wardveil`
3. **GoreeShield** — `GoreeCloud/goreeshield`
4. **GoreeCloud Identity** — `GoreeCloud/identity`
5. **GoreeCloud Mesh** — `GoreeCloud/mesh`

These are the five founder-designated MIPS platforms. Implementation and release-compliance status must be verified independently.
