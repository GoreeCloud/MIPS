# MIPS — Mandatory Integrated Platform Systems

GoreeCloud has **five** Mandatory Integrated Platform Systems (MIPS):

1. **GoreeCloud UI** — `GoreeCloud/gc-ui`
2. **Wardveil** — `GoreeCloud/wardveil`
3. **GoreeShield** — `GoreeCloud/goreeshield`
4. **GoreeCloud Identity** — `GoreeCloud/identity`
5. **GoreeCloud Mesh** — `GoreeCloud/mesh`

These are the five founder-designated MIPS platforms. Implementation and release-compliance status must be verified independently.

## Governance and release eligibility

The [canonical MIPS requirement](https://drive.google.com/file/d/1mzBTnWag2ca8wsRg9uHl4IXOkjkoTT9o/view) defines **five** platform integrations to assess for every covered GoreeCloud component before **Anchor** release eligibility. Each platform must be either integrated and verified where applicable, or determined not applicable with a documented rationale. Incomplete or undetermined assessments block a passing MIPS prerequisite.

The canonical Google Drive file retains its historical *Integral* filename for link and file-identity continuity; the current founder-designated term is **Mandatory Integrated Platform Systems**. The five-system rule does not imply deployed integrations or independently verified product compliance.
